# My GeoDev Lab Africa project
Which ward settlements in Eti-Osa LGA are located more than 2 km from the nearest health facility, and what is the expected population served by each health facility?
This project was developed over a 12-month period in collaboration with GeoDev Lab Africa, Cohort One.
